# Combined Mean-Std Summaries

This directory combines `results/avg_summary/*.csv` and `results/std_summary/*.csv` into `avg +/- std` tables for each experimental setting.

- `.csv` files use `avg +/- std` for easy spreadsheet processing.
- `.md` files provide quick Markdown previews.
- `.tex` files provide LaTeX tabular snippets using `$avg \pm std$`.

The standard deviations are sample standard deviations over `seed0`, `seed1`, and `seed2`.
