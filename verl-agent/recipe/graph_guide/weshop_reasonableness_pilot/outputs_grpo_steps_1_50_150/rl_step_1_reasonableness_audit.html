WebShop Target-Level Reasonableness Audit: RL step 1

This audit builds target-level oracle graphs from WebShop product/instruction metadata and successful rollout purchases. It marks progress when the rollout reveals the target asin, opens it, selects required options, and buys the target.

Reasonableness And SPIT Rubric

Oracle 结构：WebShop 被建模为“定序 subgoal + subgoal 内部无序 sub-step”。定序依赖为 G0 target_visible -> G1 target_product_opened -> G2 required_options_configured -> G3 target_purchased。

Case-by-case 约束：每个问题会额外生成 C0/C1/... 检查位，例如价格上界、非 option 属性/类别词匹配等。它们插在 G2 和 G3 之间，作为购买合法性的 gating check；默认不增加 SPIT 分母，也不直接匹配某个 model step。

无序 sub-step：在 G2 内部，每个必选商品选项都是一个无序覆盖位，例如 color=yellow、size=medium。只要已经打开目标商品页，先点 size 再点 color，或先点 color 再点 size，都视为等价。

Reasonable=1：当前 step 带来了新的层级 oracle 进展，或是在尚未看到目标商品前进行初始搜索。新的进展包括：看到目标 ASIN、打开目标商品、覆盖一个此前未覆盖的必选 option、或在 option 满足后购买目标商品。

Reasonable=0：动作格式错误、动作文本非英文、点击错误商品、尚未打开目标商品就点击 option、重复点击已覆盖 option、无目标进展的导航/查看动作，或购买了错误目标/错误 option。

SPIT：表格中只展示 已完成单元 / 总单元。单元包括 target_visible、target_product_opened、每个无序必选 option，以及 target_purchased。定序依赖会门控得分：option 只有在目标商品页已打开后才计入；purchase 只有在所有必选 option 已覆盖后才计入。

颜色：绿色表示该 step 产生了新的 SPIT 进展；黄色表示 step 暂时可接受但没有 SPIT 增量，例如目标出现前的初始搜索；红色表示 unreasonable / off-oracle step。
